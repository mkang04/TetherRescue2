# Rescue Outcomes

한 판이 **언제, 어떤 결과로 끝나는지** 정리한 문서입니다.
숫자는 모두 기본값이며 대부분 [`config/tow_default.yaml`](../config/tow_default.yaml)에서 바꿉니다.

> **얼굴이 물에 잠겨도 실패는 아닙니다.** 잠긴 시간은 "얼굴 물 밖 비율"과 점수에만 반영됩니다.

---

## Rescue Mission Mode

좌표 받기 → 탐색 → 접근 → 튜브 건네기 → 견인까지 하는 **전체 구조 임무**입니다.

| 결과 | 조건 |
| --- | --- |
| ✅ 구조 성공 | 줄이 연결된 상태에서 사람이 **기지 5 m 안**에 들어옴 |
| ❌ 로봇 뒤집힘 | 로봇이 **60°** 넘게 기욺 |
| ❌ 줄 끊어짐 | 줄 연결 후 **294 N**을 **0.05초** 넘게 넘음 |
| ❌ 못 찾음 | 주변 탐색(`SEARCH`)을 시작하고 **90초** 안에 사람을 '확인'하지 못함 |
| ❌ 시간 초과 | 임무 시작부터 **300초**가 지남 |

### Good to Know

- **"못 찾음"의 90초는 탐색을 시작할 때마다 새로 셉니다.**
  접근하다 놓치거나 튜브를 못 건네서 다시 탐색하면 처음부터 다시 셉니다.
  그래서 찾았다 놓쳤다를 반복하면 "못 찾음"이 아니라 **시간 초과**로 끝날 수 있습니다.
- **튜브 건네기는 그 자체로 실패하지 않습니다.**
  15초 안에 사람이 못 잡으면 위치 추정이 틀린 것으로 보고 **다시 탐색**할 뿐입니다.
- **줄 연결 전에는 줄이 끊어질 일이 없습니다.**
  사람이 튜브를 끼우기 전까지는 줄 힘을 계산하지 않습니다.

## Tow-Only Mode

처음부터 줄이 연결된 상태에서 **끌고 오기만** 합니다.

| 결과 | 조건 |
| --- | --- |
| ✅ 구조 성공 | 사람이 출발점에서 **50 m** 이동 |
| ❌ 줄 끊어짐 | **294 N**을 **0.05초** 넘게 넘음 |
| ❌ 로봇 뒤집힘 | 로봇이 **60°** 넘게 기욺 |
| ❌ 시간 초과 | **120초**가 지남 |

끌고 오기 모드는 **점수**도 계산합니다 (임시 공식).

```
점수 = 간 거리 비율 × (70 × 얼굴 물 밖 비율 + 30 × min(1, 평균 속도 / 2 m/s))
```

줄 끊어짐·로봇 뒤집힘은 0점입니다.

## Check Order

조종 한 박자(1/50초)마다 아래 순서로 확인하고, **먼저 걸린 것**으로 끝납니다.
같은 순간에 두 조건이 겹치는 일은 드물지만, 겹치면 순서가 결과를 정합니다.

| 순서 | 구조 임무 | 끌고 오기 |
| --- | --- | --- |
| 1 | 로봇 뒤집힘 | 구조 성공 |
| 2 | 줄 끊어짐 | 줄 끊어짐 |
| 3 | 구조 성공 | 로봇 뒤집힘 |
| 4 | 못 찾음 | 시간 초과 |
| 5 | 시간 초과 | |

## Where to Change

| 기준 | 설정 키 | 기본값 |
| --- | --- | --- |
| 구조 성공 거리 (구조 임무) | `mission.home_radius` | 5 m |
| 구조 성공 거리 (끌고 오기) | `sim.goal_distance` | 50 m |
| 줄 끊어지는 힘 | `tether.break_force` | 294 N |
| 끊어지기까지 버티는 시간 | `tether.break_hold` | 0.05 s |
| 탐색 제한 시간 | `mission.search_timeout` | 90 s |
| 튜브 건네기 제한 시간 (넘으면 다시 탐색) | `mission.handoff_timeout` | 15 s |
| 전체 제한 시간 (구조 임무) | `mission.max_time` | 300 s |
| 전체 제한 시간 (끌고 오기) | `sim.max_time` | 120 s |
| 뒤집힘 각도 | 코드 상수 `CAPSIZE_ANGLE` ([tow_env.py](../tether_rescue/tow_env.py)) | 60° |

판정 코드: 구조 임무는 [`mission_sim.py`](../tether_rescue/mission/mission_sim.py), 끌고 오기는 [`tow_env.py`](../tether_rescue/tow_env.py)의 `_check_done`.
